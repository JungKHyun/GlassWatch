# 집중해! (Pomodoro_cld)

## 무엇을 하는 프로그램인가요?

`집중해!`는 화면 위에 항상 떠 있는 작은 집중 타이머입니다. 문서 작성, 독서, 공부, 회의 준비처럼 일정 시간 동안 한 가지 일에 집중할 때 사용하세요.

창을 다른 프로그램 위에 올려둘 수 있고, 투명도와 크기를 조절할 수 있습니다.

## 실행 방법

Windows에서는 아래 파일을 실행하세요.

`dist-v10/win-unpacked/집중해!.exe`

중요: `집중해!.exe`만 따로 복사하지 마세요. 실행에 필요한 DLL과 프로그램 파일이 함께 있으므로 `dist-v9/win-unpacked` 폴더 전체를 그대로 유지해야 합니다.

## 사용 방법

1. `10`, `45`, `60` 버튼 중 원하는 집중 시간을 선택합니다.
2. 직접 시간을 정하려면 아래 입력칸에 분 단위 숫자를 입력하고 `▶` 버튼을 누릅니다.
3. `Start`를 누르면 타이머가 시작됩니다.
4. 진행 중에는 `Pause`로 멈추고, 다시 `Continue`로 이어서 진행할 수 있습니다.
5. `Reset`을 누르면 현재 선택한 시간으로 초기화됩니다.

## 막대그래프 사용법

세로 막대는 남은 시간을 보여줍니다. 시간이 줄어들수록 막대가 위에서 아래 방향으로 줄어듭니다.

막대를 클릭하면 색상이 다음 순서로 바뀝니다.

`파랑 → 빨강 → 노랑`

상단의 `집중해!` 제목 색상도 막대 색상에 맞춰 함께 바뀝니다.

## 투명도와 크기

- `투명도`: 창의 불투명도를 35~100%로 조절합니다.
- `크기`: 창과 내용을 75~135%로 확대·축소합니다.
- 창의 빈 공간을 드래그하면 원하는 위치로 옮길 수 있습니다.

## 타이머 종료

시간이 끝나면 창이 깜빡이고 완료 상태로 멈춥니다. 알림음이 켜져 있으면 beep 소리가 3번 울립니다.

왼쪽 위 `♪` 버튼으로 알림음을 켜고 끌 수 있습니다(꺼지면 흐리게 표시). 설정은 다음 실행 때도 유지됩니다. 다시 `Restart`를 누르면 같은 시간으로 다시 시작할 수 있습니다.

## 개발자용 실행 및 빌드

Node.js가 설치된 환경에서는 다음 명령으로 개발 실행과 Windows 빌드를 할 수 있습니다.

```bash
npm install
npm start
npm run dist
```

## 기본 동작

- 다른 창보다 항상 위에 표시됩니다.
- 작업표시줄에는 별도 창으로 표시하지 않습니다.
- 창을 닫으려면 오른쪽 위 `×` 버튼을 누릅니다.
